## 真正完成的原型

自行產生人體的軀幹輪廓、頭部與臉、手臂連續蒙皮、肘／腕骨架、手掌與手指、髖腿、鞋與服裝；不是火柴人、線條或靜態圖。沒有下載或購買人體模型、動畫與影片。啞鈴為原創網格，彈力繩為連續更新的立體管段。

- 啞鈴二頭肌彎舉：屈肘動畫、啞鈴隨手掌移動，上臂維持側身，主要二頭肌概略區域標示。
- 坐姿彈力繩划船：腳底繞繩、拉回／控制回程、背部主要區域與二頭次要參與標示。
- 徒手臀橋：腳位置固定、肩髖膝幾何約束、臀部與腹／腿後次要區域標示。以有限幅度避免刻意過度抬高。
- 播放、暫停、重播、0.5／0.75／1／1.25倍速、拖曳動作進度、前／側／背視角、拖動旋轉、遠近。
- 有文字姿勢、常見錯誤、替代方式與來源連結。
- 背景事件會暫停並要求手動恢復；此處只是動畫播放，不是正式跟練計時或完成判定。

肌群色塊是表面概略區域，不是醫學精度的分層肌肉模型或實測發力。人物外觀為第一版原創低細節運動人偶，仍須使用者驗收，不宣稱商業App品質。

## 資料隔離與隱私

不同路徑本身不能隔離儲存。這個版本使用外層靜態入口與sandbox=allow-scripts內頁，刻意不給allow-same-origin，使內頁成為opaque origin。正式App從未嵌入、匯入或被原型初始化。

真Chromium測試用合成哨兵資料建立與正式相同名稱的localStorage，以及測試IndexedDB，再開預覽驗證：

| 嘗試 | 結果 |
|---|---|
| localStorage | SecurityError |
| sessionStorage | SecurityError |
| IndexedDB open | SecurityError |
| 父頁DOM | SecurityError |
| 頂層localStorage | SecurityError |

外層localStorage、sessionStorage、IndexedDB哨兵及不相關鍵值保持原值。預覽程式沒有儲存API、資料庫、Service Worker、正式資料匯入或postMessage橋接；connect-src none。不讀、不寫、不自動保存訓練。只在當頁記憶體運作，重新載入不保存進度。

預覽沒有使用者個人備份、歷史紀錄、身高／年齡／體重預設、密碼或API金鑰。沒有把測試資料匯入正式站。

### 原型負擔

- 正式首頁原檔增加：0 bytes；3D不由正式首頁載入。

瀏覽器安裝套件在測試環境執行，不要求使用者電腦或iPhone安裝。實際iPhone GPU、溫度、耗電與滑動仍未測量，不能宣稱不卡頓。

## 請用筆電／iPhone驗收

1. 開啟隔離預覽入口，確認頂端明示非正式功能。
2. 依序選啞鈴彎舉、彈力繩划船、臀橋；確認人物是可辨識立體人體，器材隨動作移動，外觀是否接受。
3. 播放／暫停／重播，選0.5倍速；拖進度觀察起始、中段、頂端與回程。
4. 用正面、側面、背面與拖曳旋轉，檢查肌群色塊與動作，不把概略色塊當實際發力。
5. iPhone上檢查每個按鈕、畫面橫溢、滑動、動畫是否明顯卡頓或發熱。
6. 切至其他App或鎖屏後回來，確認已暫停、不自動跳過動作，再手動播放。
7. 關閉重開預覽，確認不保存正式訓練；另開原正式網站，檢查歷史仍在。不需要清除任何網站資料。
8. 原型經外觀確認後，才進入智慧課表與正式跟練里程碑；正式發布另行授權。

## 直接線上瀏覽器的限制

直接用測試Chromium開HTTPS預覽時回報ERR_CERT_AUTHORITY_INVALID。沒有關閉憑證驗證、忽略HTTPS錯誤或繞過警告，因此這一項未通過，不能把HTTP抓檔成功當成真瀏覽器線上操作成功。此限制不等於已證實使用者Safari會遇到相同問題。

另以HTTPS下載並比對SHA的原檔，在本機HTTP測試來源以真Chromium重新驗證；測試來源與真HTTPS網站不能混稱。iPhone真機與使用者的HTTPS瀏覽仍待驗收。
