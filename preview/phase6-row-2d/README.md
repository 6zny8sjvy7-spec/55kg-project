# 55 KG PROJECT｜2D／2.5D 坐姿彈力繩划船 M1 預覽

本頁是獨立的可操作教學樣本，並非已驗收的正式3D教練。只新增preview/phase6-row-2d/，正式index.html、資料、計算與舊preview保持原樣。

## 真正實作

同角色四個固定角度；以批准外觀衍生的2D素材、固定頭臉／軀幹與分層手臂做關節路徑動畫。不是GLB、動作捕捉、影片或光流補間。播放／暫停／重播／0.5、0.75、1倍速／進度／四步拆解／角度／肌群／手肘與手及肩胛軌跡皆有實際程式。

腳底固定、膝微彎、背部中立版本。深紅主肌群、橘色次要、低亮度穩定肌；菱形肌是深層區域虛線。提示是教學區域，非精密肌肉邊界或即時量測。

## 隔離

外層iframe只有allow-scripts與開啟來源連結所需的popup權限，沒有allow-same-origin。實測子頁origin為null，讀父頁DOM、localStorage與IndexedDB均遭SecurityError。沒有儲存紀錄、第三方API、Service Worker、IndexedDB、Cache API或食品資料庫載入程式。不靠網址路徑或manifest scope宣稱儲存隔離。

每次只載入所選角度一張小型WebP atlas，JS最多保留最近兩個角度影像參照；瀏覽器可能自行保留HTTP／影像快取，不宣稱記憶體硬上限或跨啟動離線。主App沒有引入此頁，首頁新增下載量為0。

## 已知品質／驗收邊界

人物為AI衍生素材，四視角外觀由同一參考生成；不是精準幾何投影。分層關節與肩部接縫仍可見；有局部修補像素，不能宣稱商業角色動畫品質。背面前臂在軀幹前側，依遮擋順序隱藏；側面只呈現近側可見手臂，並非刪除另一手。
